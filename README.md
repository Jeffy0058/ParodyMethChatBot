# 🧪 [He]isenberg [Ma]rket — Parody E-Commerce & RAG Lab Assistant

> ⚠️ **คำเตือน (Parody & Educational Disclaimer):**  
> โปรเจกต์นี้เป็น **เว็บไซต์ Static ล้อเลียน (Parody / Satire)** ที่สร้างขึ้นเพื่อความบันเทิงและการศึกษาในรายวิชา *ปัญญาประดิษฐ์และการเรียนรู้ของเครื่อง (AI & Machine Learning)* เท่านั้น โดยได้แรงบันดาลใจจากซีรีส์ *Breaking Bad* ไม่มีการจำหน่ายสินค้าผิดกฎหมาย ไม่มีระบบรับเงินจริง และไม่มีการเก็บข้อมูลส่วนบุคคลใดๆ

## 📖 เกี่ยวกับโปรเจกต์ (Overview)

**Heisenberg Market** คือเว็บแอปพลิเคชันร้านค้าออนไลน์แนวล้อเลียนที่ผสานรวมกับ **RAG Chatbot (Retrieval-Augmented Generation)** ซึ่งทำหน้าที่เป็นผู้ช่วยอัจฉริยะประจำแล็บ คอยตอบคำถามลูกค้าจากฐานข้อมูลเอกสารของร้านได้อย่างแม่นยำ พร้อมระบบอ้างอิงแหล่งที่มาของข้อมูลแบบโปร่งใส

### ✨ ฟีเจอร์เด่นของหน้าร้าน (Parody Storefront)
* **💎 แค็ตตาล็อกสินค้าแล็บ 8 รายการ:** เช่น *Blue Sky Crystal 99.1% (ลูกอมรสมินต์)*, *Chili P Special Edition*, *แป้งทอดไก่ Los Pollos* และ *ชุดหมีกันฝุ่นสีเหลือง* พร้อมหน้าต่างส่องส่วนผสมเคมีปลอมและรีวิวจากตัวละครในซีรีส์
* **🛍️ ระบบตะกร้า "ถุงซิปล็อก" & โค้ดลับ:** เพิ่ม/ลดสินค้า เลือกวิธีจัดส่งสุดปั่น (*รถบ้าน RV*, *รถขนไก่ Los Pollos*, *นกพิราบสื่อสาร*) และใช้โค้ดส่วนลด `HEISENBERG`, `YO`, `SAUL` พร้อมออกใบเสร็จทิพย์ที่คัดลอกไปแชร์ได้
* **🚨 ระบบวัดระดับ DEA Threat & สุ่มโดนแฮงค์บุกจับ:** แถบแจ้งเตือนด้านบนจะเปลี่ยนสีตามจำนวนของในตะกร้า และมีโอกาส 25% ที่ **ASAC Hank Schrader** จะบุกจับตอนกดสั่งซื้อ (ต้องกดปุ่ม **Better Call Saul** เพื่อเคลียร์คดี!)
* **🧹 โหมดหนีตำรวจ (Panic Camouflage Mode):** กดปุ่มสีเหลืองมุมขวาบนเพื่อแปลงร่างหน้าเว็บให้กลายเป็น **"ร้านซ่อมเครื่องดูดฝุ่น Best Quality Vacuum"** ทันที

### 🤖 ฟีเจอร์ของระบบแชตบอต (RAG Chatbot)
* **ตอบคำถามยึดตามเอกสาร (Grounded Generation):** บังคับให้ AI ตอบเฉพาะข้อมูลที่มีอยู่ในโฟลเดอร์ `docs/` เท่านั้น หากไม่พบข้อมูลจะแนะนำให้ติดต่อทนาย Saul Goodman โดยไม่เดาคำตอบมั่ว
* **ค้นหาได้ 2 โหมด (`SEARCH_MODE`):**
  * `vector`: ค้นหาด้วยความหมาย (Semantic Search) ผ่านไฟล์ `vectors.json` ที่สร้างไว้ล่วงหน้า
  * `local`: ค้นหาด้วยการเทียบชุดตัวอักษร (3-gram) ในเบราว์เซอร์ ทำงานได้แม้ไม่ได้เชื่อมต่อ Embedding API
* **แสดงแหล่งอ้างอิงทุกคำตอบ:** ระบุชื่อไฟล์ หมายเลขส่วน (Chunk) และคะแนนความใกล้เคียงใต้ข้อความตอบกลับทุกครั้ง

## 🏗️ สถาปัตยกรรมระบบ (System Architecture)

โปรเจกต์นี้ทำงานในรูปแบบ **Static Site + Serverless Proxy** เพื่อความปลอดภัยของ API Key และไม่ต้องเสียค่าเช่าเซิร์ฟเวอร์:

1. **Frontend (`GitHub Pages`):** รันไฟล์ `index.html` และ `chat-widget.js` บนเบราว์เซอร์ของผู้ใช้
2. **Knowledge Base (`docs/` & `vectors.json`):** เก็บข้อมูลกฎระเบียบ สินค้า โปรโมชัน และช่องทางติดต่อของร้านในรูปแบบไฟล์ `.txt` และเวกเตอร์ที่แปลงไว้ล่วงหน้า
3. **Serverless Proxy (`Cloudflare Worker`):** ทำหน้าที่เป็นตัวกลางเก็บ `OPENROUTER_KEY` ไว้เป็นความลับบนเซิร์ฟเวอร์ และตรวจสอบโดเมนต้นทาง (`CORS`) ก่อนส่งคำขอต่อไปยัง AI
4. **LLM & Embedding (`OpenRouter`):** ประมวลผลภาษาธรรมชาติและแปลงข้อความเป็นเวกเตอร์

## 🚀 วิธีติดตั้งและอัปเดตข้อมูล (Setup & Maintenance)

### 1. การตั้งค่า Cloudflare Worker
1. สร้าง Worker บน [Cloudflare Dashboard](https://dash.cloudflare.com/) และนำโค้ดจาก `worker.js` ไปวางในส่วน **Edit code**
2. แก้ไขรายการ `ALLOWED` ให้ตรงกับโดเมน GitHub Pages ของคุณ (เช่น `https://jeffy0058.github.io`)
3. ไปที่ **Settings > Variables and Secrets** เพิ่มตัวแปรแบบ **Secret** ชื่อ `OPENROUTER_KEY` และใส่รหัส Key จาก OpenRouter
4. เปิดลิงก์ Worker เพื่อตรวจสอบว่าแสดงผล `{"status":"ok","hasKey":true}`

### 2. การอัปเดตเอกสารในอนาคต
หากมีการแก้ไข เพิ่ม หรือลบไฟล์ `.txt` ในโฟลเดอร์ `docs/`:
1. อัปเดตรายชื่อไฟล์ในตัวแปร `FILES` ภายในไฟล์ `config.js` (กรณีเพิ่มหรือลบไฟล์)
2. เปิดหน้า `build-vectors.html` ผ่านลิงก์เว็บของคุณ แล้วกด **"เริ่มสร้าง"** เพื่อดาวน์โหลดไฟล์ `vectors.json` ฉบับใหม่
3. นำไฟล์ `vectors.json` ใหม่ไปอัปโหลดทับไฟล์เดิมบน GitHub Repository
